# c0dewars Homebrew tap

```sh
brew install c0dewars/tap/kborg
```

[KBorg](https://github.com/c0dewars/kborg) is a fast, secure Kubernetes terminal UI. The formula builds from the tagged source release with Homebrew's Rust; see the project's [Homebrew notes](https://github.com/c0dewars/kborg/blob/main/docs/HOMEBREW.md).
