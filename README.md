# c0dewars Homebrew tap

```sh
brew install c0dewars/tap/kborg
brew install --cask c0dewars/tap/hypermac
```

[KBorg](https://github.com/c0dewars/kborg) is a fast, secure Kubernetes terminal UI. The formula builds from the tagged source release with Homebrew's Rust; see the project's [Homebrew notes](https://github.com/c0dewars/kborg/blob/main/docs/HOMEBREW.md).

[HyperMac](https://github.com/c0dewars/HyperMac) is a native macOS tiling window manager for Apple Silicon (macOS 14+). The cask installs the ad-hoc signed preview DMG from HyperMac's GitHub Releases; it is not notarized, so macOS may ask you to use **Open Anyway** once. Grant Accessibility permission after installing.
